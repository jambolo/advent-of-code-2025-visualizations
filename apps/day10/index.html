Day 10: Factory

Just across the hall, you find a large factory. Fortunately, the Elves here have plenty of time to decorate. Unfortunately, it's because the factory machines are all offline, and none of the Elves can figure out the initialization procedure.

The Elves do have the manual for the machines, but the section detailing the initialization procedure was eaten by a Shiba Inu. All that remains of the manual are some indicator light diagrams, button wiring schematics, and joltage requirements for each machine.

Part 2 - Joltage Configuration

All of the machines are starting to come online! Now, it's time to worry about the joltage requirements.

Each machine needs to be configured to exactly the specified joltage levels to function properly. Below the buttons on each machine is a big lever that you can use to switch the buttons from configuring the indicator lights to increasing the joltage levels.

How Buttons Work

The machines each have a set of numeric counters tracking its joltage levels, one counter per joltage requirement. The counters are all initially set to zero.

Joltage requirements like {3,5,4,7} mean that the machine has four counters which are initially 0 and that the goal is to simultaneously configure the first counter to be 3, the second counter to be 5, the third to be 4, and the fourth to be 7.

A button wiring schematic like (1,3) means that each time you push that button, the second and fourth counters would each increase by 1.

Example

[.##.] (3) (1,3) (2) (2,3) (0,2) (0,1) {3,5,4,7}

Configuring this machine's counters requires a minimum of 10 button presses. One way to do this is by pressing (3) once, (1,3) three times, (2,3) three times, (0,2) once, and (0,1) twice.

Your Puzzle

Analyze each machine's joltage requirements and button wiring schematics. What is the fewest button presses required to correctly configure the joltage level counters on all of the machines?

Answer

Part 1: 532 (indicator lights)

Part 2: 18,387 (joltage counters)

How the Solution Works

Overview

The solver uses Integer Linear Programming (ILP) to find the minimum number of button presses needed to configure each machine's joltage counters.

The Mathematical Model

For each machine, we solve the matrix equation: XB = J

  • X: Vector of button press counts (what we're solving for)
  • B: Button matrix - each row is a button, each column indicates which counters it affects (0 or 1)
  • J: Joltage requirements - target values for each counter

Example

For a machine with buttons (0,1), (1,2), and (2,3) targeting {3, 5, 4, 7}:

Button 0 affects counters: 0, 1 → [1, 1, 0, 0] Button 1 affects counters: 1, 2 → [0, 1, 1, 0] Button 2 affects counters: 2, 3 → [0, 0, 1, 1] Target joltages: [3, 5, 4, 7] Minimize: x0 + x1 + x2 Subject to: x0 = 3 (counter 0) x0 + x1 = 5 (counter 1) x1 + x2 = 4 (counter 2) x2 = 7 (counter 3)

Algorithm Steps

  1. Parse Input: Extract button configurations and joltage targets for each machine
  2. Build Matrix: Create the button matrix B where B[i][j] = 1 if button i affects counter j
  3. Set Up ILP: Define variables for each button's press count (non-negative integers)
  4. Add Constraints: For each counter, sum of (button presses × button effect) must equal target
  5. Minimize: Sum of all button presses
  6. Solve: Use the CBC solver to find optimal solution
  7. Aggregate: Sum minimum presses across all 180 machines

Why ILP?

This problem is a system of linear equations with integer constraints. ILP (Integer Linear Programming) is the perfect tool because:

  • Button presses must be whole numbers
  • We want to minimize total presses
  • The constraints are linear (sums of button effects = targets)

Complexity

With 180 machines, each with varying numbers of buttons (typically 3-13) and counters (typically 4-10), the solver efficiently finds optimal solutions using the CBC (COIN Branch and Cut) library.
