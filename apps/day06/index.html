Day 6: Trash Compactor

After helping the Elves in the kitchen, you were taking a break and helping them re-enact a movie scene when you over-enthusiastically jumped into the garbage chute!

A brief fall later, you find yourself in a garbage smasher. Unfortunately, the door's been magnetically sealed.

As you try to find a way out, you are approached by a family of cephalopods! They're pretty sure they can get the door open, but it will take some time. While you wait, they're curious if you can help the youngest cephalopod with her math homework.

Cephalopod math doesn't look that different from normal math. The math worksheet (your puzzle input) consists of a list of problems; each problem has a group of numbers that need to be either added (+) or multiplied (*) together.

However, the problems are arranged a little strangely; they seem to be presented next to each other in a very long horizontal list:

123 328  51 64
 45 64  387 23
  6 98  215 314
*   +   *   +

Each problem's numbers are arranged vertically; at the bottom of the problem is the symbol for the operation that needs to be performed. Problems are separated by a full column of only spaces.

Part 1 Answer: 5,227,286,044,585

Part Two

The big cephalopods come back to check on how things are going. When they see that your grand total doesn't match the one expected by the worksheet, they realize they forgot to explain how to read cephalopod math.

Cephalopod math is written right-to-left in columns. Each number is given in its own column, with the most significant digit at the top and the least significant digit at the bottom.

Reading the problems right-to-left one column at a time, the problems are now quite different:

  • The rightmost problem is 4 + 431 + 623 = 1058
  • The second problem from the right is 175 * 581 * 32 = 3253600
  • The third problem from the right is 8 + 248 + 369 = 625
  • Finally, the leftmost problem is 356 * 24 * 1 = 8544

Now, the grand total is 1058 + 3253600 + 625 + 8544 = 3263827.

Part 2 Answer: 10,227,753,257,799

How the Solver Works

The solver reads the math worksheet using cephalopod reading rules: right-to-left, with numbers built from vertical columns.

The Algorithm

  1. Parse the grid: Read the worksheet as a 2D character array.
  2. Identify problem boundaries: Find columns that are entirely spaces — these separate problems.
  3. Process right-to-left: Start from the rightmost problem and work left.
  4. Read each column: Within a problem, each column represents one number. Read digits top-to-bottom (most significant digit at top).
  5. Extract operator: The bottom row contains + or *.
  6. Calculate: Apply the operation to all numbers in the problem.
  7. Sum results: Add each problem's result to get the grand total.

Column Reading Example

For the column with characters 1, 4, 6 (top to bottom), the number is 146.

Empty cells or spaces in a column are ignored — only digits contribute to the number.

What the Visualization Shows

  • Grid display: The worksheet with character cells visible.
  • Active problem highlight: Glowing columns for the current problem.
  • RTL indicator: Arrow showing the right-to-left reading direction.
  • Calculation panel: Numbers, operator, and result for the current problem.
  • Running total: Accumulated sum as problems are solved.

Scale

The worksheet contains many problems, and numbers can be quite large. The final answer — 10,227,753,257,799 — demonstrates the scale of the calculations involved.
